Installation
============

**Requirements**

- Python >= 3.10
- PyTorch >= 2.0
- dependencies = ``torch``, ``torchmetrics``, ``numpy``, ``h5py``, ``matplotlib``


**Install from source**

Clone the repository and install it in editable mode using ``uv`` or ``pip``:

.. code-block:: bash

   git clone https://github.com/yourusername/MLGWSC_proposal.git
   cd MLGWSC_proposal
   pip install -e .

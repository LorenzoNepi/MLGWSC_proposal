Installation
============

**Requirements**

- **Python** >= 3.12.3
- **PyThorch (`torch`)** >= 2.15.0
- **`torchmetrics`** >= 1.9.0
- **NumPy** >= 2.5.3
- **h5py** >= 3.16.0
- **Matplotlib** >= 3.11.2


**Install from source**

Clone the repository and install it in editable mode using ``uv`` or ``pip``:

.. code-block:: bash

   git clone https://github.com/yourusername/MLGWSC_proposal.git
   cd MLGWSC_proposal
   pip install -e .
